 # Sona - Hostel Management (React + Tailwind)


1. Create folder `sona` and paste the files with exact paths.
2. Run `npm install` to install dependencies listed in package.json.
3. Run `npm start` to start the dev server.


Notes:
- This is a standalone frontend-only demo that uses localStorage to persist data. You can later connect it to a backend (Node + Express + MongoDB) if you want.
- Tailwind is used for quick UI. If you face issues, ensure devDependencies are installed and PostCSS is available.
